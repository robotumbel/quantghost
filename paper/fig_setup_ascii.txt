[ ATTACKER  —  build the QuantGhost stego model ]

  +------------------+          +---------------------------------------------+
  | Pre-trained      |          |  PAYLOAD PREPARATION                        |
  | FP32 model   W   |          |   raw payload                               |
  +--------+---------+          |     |  AES-CTR encrypt  -> uniform ciphertext|
           |                    |     v                                       |
           |                    |   LDPC / fountain ECC   (erasure repair)    |
           |                    |     |  tile x r   (redundancy  r = P / L)    |
           |                    |     v   coded payload bits  b                |
           |                    +-----------------------+---------------------+
           |                                            |
           v                                            v
  +-----------------------------------------------------------------------+
  |  QuantGhost EMBED   (Algorithm 1, applied per weight tensor)          |
  |   1.  scale     s = max|W| / qmax            (qmax = 127 for INT8)    |
  |   2.  code      q = clip( round(W / s), -qmax, qmax )                 |
  |   3.  write     LSB(|q|) <- b                (payload in INT8 code)   |
  |   4.  stealth   W~ = ( q + u ) * s ,   u ~ Uniform(-0.49, 0.49)       |
  |   5.  pin       hold one max weight at |q|=qmax  ->  victim's         |
  |                 recomputed scale equals s  (grids coincide)          |

--------------------------------------------------------------------------------
 THE LIMIT  (capacity-robustness-stealth trilemma):
   NeuPerm erases the high-capacity positional payload   (1.000 -> 0.508),
   but the permutation-INVARIANT channel survives,  bounded by
             C  <=  SUM_layers  k_h * k_w     (= 196 bits on ResNet-18)
   enough to bootstrap a key / URL / decryptor seed.
